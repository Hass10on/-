# صافرة المسيرة

لعبة محاكاة لمسيرة حكم كرة قدم من منظور الشخص الأول، تعمل في المتصفح (ملف `index.html` واحد يستخدم Three.js).

## الفكرة
تبدأ حكماً في **دوري الأحياء** وتصعد سلّم التحكيم: الدرجة الثانية ← الدوري الممتاز ← البطولة القارية ← **كأس العالم**، وصولاً إلى نهائي كأس العالم.

- **داخل الملعب:** تتحرك في الملعب بنفسك. عند كل تدخّل يتباطأ الزمن ولديك ثوانٍ لتقرر. ما تعرفه عن اللقطة يعتمد على موقعك وزاوية نظرك، وعلى ما إذا كان أحد اللاعبين يحجب رؤيتك.
- **بعد المباراة:** تقرير مراقب الحكام، ثم مؤتمر صحفي عن القرارات الجدلية.
- **خارج الملعب:** تختار كل أسبوع كيف تستعد (لياقة، قوانين، تحليل فيديو)، وتظهر أحداث عشوائية مثل عروض الرشوة والإصابات ودعوات الإعلام.
- **المؤشرات:** السمعة، اللياقة، النزاهة، ثقة الاتحاد. هي التي تحدد ترقيتك أو هبوطك أو نهاية مسيرتك.

## التحكم
| المفتاح | الوظيفة |
|---|---|
| W A S D | التحرك |
| Shift | جري سريع (يستهلك اللياقة) |
| الفأرة | النظر |
| Q | استمرار اللعب |
| F | خطأ |
| Y | صفراء للمتدخّل |
| R | حمراء للمتدخّل |
| T | صفراء للتمثيل (للاعب الذي ارتمى) |
| Esc / P | إيقاف مؤقت |

على الهاتف: عصا تحكم للحركة، والسحب على الشاشة للنظر، وأزرار للقرارات.

## التشغيل
افتح `index.html` في المتصفح (يحتاج اتصالاً بالإنترنت لتحميل Three.js والخطوط).
